## Fraud Detection & Money Mule Account Analysis
## Overview

This project was completed as part of the Experian Virtual Experience Programme.

The objective was to analyse account-holder and transaction-related datasets to identify characteristics associated with potential money mule accounts. The project demonstrates practical data analytics techniques including data cleaning, feature engineering, exploratory data analysis, and visualisation.

## Project Objectives
Analyse account-holder data and fraud indicators
Identify demographic patterns associated with mule accounts
Perform data cleaning and preprocessing
Engineer analytical features for fraud investigation
Visualise fraud-risk trends across customer segments
Technologies Used
Python
Pandas
Matplotlib
NumPy
## Key Tasks
Data Preparation
Processed multiple datasets containing account, customer, and fraud-flag information
Handled missing values and duplicate records
Created a consolidated analytical dataset
Feature Engineering
Calculated customer age from date-of-birth data
Created age-group categories for demographic analysis
Generated variables suitable for fraud investigation workflows
Exploratory Analysis
Analysed money mule account distribution by age group
Analysed money mule account distribution by gender
Investigated demographic patterns associated with fraudulent activity
Data Visualisation
Created bar charts to communicate fraud trends
Presented demographic risk patterns through visual analytics
## Skills Demonstrated
Data Cleaning

Fraud Analytics

## Results

The analysis identified demographic patterns among flagged money mule accounts and demonstrated a structured approach to fraud-risk investigation using Python-based analytics.
